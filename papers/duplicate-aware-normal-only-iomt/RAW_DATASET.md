# Original Dataset — CICIoMT2024

## Official Source

Canadian Institute for Cybersecurity (CIC)
University of New Brunswick

https://www.unb.ca/cic/datasets/iomt-dataset-2024.html

## Data Retention Policy

- Original raw PCAP files are not hosted in this repository.
- Original raw PCAP files must be obtained from the official dataset provider.
- The 114 CSV files already archived in Git LFS are retained.
- Research notebooks, experimental configurations, results,
  publication archives, and references are preserved.
- The original dataset directory structure and file manifests
  are retained for traceability.

## Reproducibility

To reproduce experiments requiring raw packet captures:

1. Obtain CICIoMT2024 from the official source.
2. Restore the original dataset directory structure.
3. Consult the dataset manifests in DataSet/CICIoMT2024/.
4. Verify downloaded files against official checksums,
   if provided by the dataset publisher.
5. Run the documented experiment notebooks.

The raw PCAP files are external research dependencies.
